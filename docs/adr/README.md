# Architecture Decision Records

Each ADR captures **one** decision: the context, the options weighed, what we
chose, and the trade-off we accepted. They are the "why" behind the code — read
them to understand (or defend) any design choice in CloudNova.

Format: [MADR](https://adr.github.io/madr/)-lite. New decisions get the next
number and never edit an old one — supersede it instead.
