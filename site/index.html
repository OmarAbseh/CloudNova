Three commands to a real answer

The engine runs anywhere Python does. Start on a laptop, then put the same thing in CI.

Scan what you have

Point it at a directory of infrastructure code. Nothing leaves the machine.

cloudnova scan ./infra

See the chains

Findings become paths, and the posture score shows every input that produced it.

cloudnova scan ./infra --format sarif

Keep it honest

Compare against the last run and fail the build when something new appears.

cloudnova monitor ./infra --fail-on-new

Authorization first, by construction

The offensive half of this tool refuses to run against anything you have not attested you may test. That is not a setting, it is how the code is shaped.

  • Deny by defaultEvery target-facing action passes a scope gate. No scope file, no run.
  • Read only against live cloudsCloud scanning uses each provider's own credential chain and never writes.
  • Severity is not confidenceA guess is never presented as a fact, and both numbers are always shown.
  • Your data stays yoursScans run locally. Results are scoped to your organization by database policy, not by application code.
